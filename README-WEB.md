# T-Connect Web v2.28

Web version preserving the v2.27 interface.

## Map
Uses Leaflet + OpenStreetMap as the alternate map. No Google Maps API key is required.

## Run locally
Serve this folder with a local HTTP server. Opening `index.html` directly via `file://` may restrict some browser APIs.

## Deploy
Upload the web root to a static hosting service such as GitHub Pages, Cloudflare Pages, or Vercel.
The existing Supabase configuration should remain in its original config file.
